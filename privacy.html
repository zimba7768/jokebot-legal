Privacy Policy

Last updated: September 2026

1. Data Collection

JokeBot Pipeline accesses only the minimum profile data and upload tokens necessary to publish authorized video files to the configured account via the TikTok API.

2. Use of Information

Collected authentication tokens are stored locally on a secured private server environment and are strictly utilized to execute scheduled video uploads. No personal data, viewer analytics, or credentials are sold, transferred, or shared with third parties.

3. Token Retention & Security

OAuth tokens are kept within restricted environment variables. Revoking application permissions inside your TikTok account instantly renders all stored credentials inactive.

4. Contact

For questions regarding this policy, reach out via the repository administrator profile.
